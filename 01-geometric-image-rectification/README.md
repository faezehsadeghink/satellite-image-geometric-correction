# SPOT Image Geometric Rectification

ترمیم هندسی تصویر خام SPOT با نقاط کنترل زمینی و نقاط کنترل مستقل و مقایسه مدل‌ها بر اساس RMSE.

## Methods
Affine, conformal, projective, second/third-degree polynomial and combined models; residual-vector analysis; nearest-neighbor and bilinear resampling.
