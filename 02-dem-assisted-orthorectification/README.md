# DEM-Assisted SPOT Orthorectification

تولید ارتوفتو از تصویر SPOT با استفاده از DEM، مقایسه مدل‌های هندسی و دو روش بازنمونه‌برداری.

## Methods
DEM sampling, affine/polynomial/DLT/RFM experiments, forward modeling, RMSE analysis, nearest-neighbor and bilinear resampling.
